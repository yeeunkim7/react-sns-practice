# React SNS Practice 

인프런 한입 크기로 잘라먹는 실전 프로젝트라는 수업을 보며 학습한 클론 기반 학습 프로젝트로,  
React + TypeScript 환경에서 **SNS 서비스의 핵심 기능들을 직접 구현하며**  
프론트엔드 아키텍처와 상태 관리, 인증 흐름을 학습하기 위해 진행한 클론 코딩 프로젝트입니다.

---

## 🔧 Tech Stack

- React
- TypeScript
- Vite
- Supabase (Auth, Storage, RLS)
- TanStack Query
- Zustand
- Tailwind CSS
- shadcn/ui

---

## ✨ Implemented Features

- 이메일 회원가입 / 로그인
- GitHub 소셜 로그인
- 세션 기반 인증 상태 관리
- RLS(Row Level Security)를 활용한 사용자별 데이터 접근 제어
- TanStack Query 기반 피드 무한 스크롤
- Supabase Storage를 이용한 이미지 업로드
- RPC 기반 좋아요 동시성 처리
- 재귀 컴포넌트를 활용한 무한 중첩 댓글
- 다크 / 라이트 / 시스템 테마 지원 (persist 적용)

---

## 🎯 Project Purpose

본 프로젝트는 기존 SNS 서비스 구조를 참고한  
**클론 기반 학습 프로젝트**입니다.

서비스 기획이나 상용 운영 목적이 아닌,  
React 환경에서 **실무에서 자주 사용되는 기능들을 직접 구현해보며**  
데이터 흐름, 상태 관리, 인증 구조에 대한 이해를 높이는 것을 목표로 했습니다.
